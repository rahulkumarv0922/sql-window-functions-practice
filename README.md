# SQL Window Function Practice

This repository contains datasets and queries for mastering SQL window functions. Includes:

- Table creation scripts
- Insert data scripts
- 10 real-world queries using window functions

## Topics Covered

- RANK, DENSE_RANK, LAG, LEAD
- ROWS BETWEEN, PARTITION BY
- Cumulative sum, rolling averages
- Salary comparisons and more

Practice-ready for PostgreSQL or PySpark SQL.
